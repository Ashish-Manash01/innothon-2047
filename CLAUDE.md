# Instructions for Claude Code

This repo is the ExxonMobil INNOTHON 2026 project: a forecast of India's electricity generation in 2047, a least-cost regional generation mix, and a Streamlit dashboard that runs the models live.

## Deploy the dashboard (the task you are most likely here for)
1. Check that it works locally first:
   `pip install -r requirements.txt && python tests/test_app.py`
   It must end with "All passed".
2. Create a **public** GitHub repository under the user's account, named `innothon-2047` unless they say otherwise. Push this folder to branch `main`:
   `gh repo create innothon-2047 --public --source=. --remote=origin --push`
   A public repo is needed for free Streamlit Community Cloud hosting.
3. Streamlit Community Cloud has no CLI. Give the user these steps:
   1. Open https://share.streamlit.io and sign in with GitHub.
   2. Click **Create app**, then **Deploy a public app from GitHub**.
   3. Set the repository to `<user>/innothon-2047`, the branch to `main`, and the main file path to `streamlit_app.py`.
   4. Under **Advanced settings**, set Python to 3.13.
   5. Click **Deploy**. The first build takes about 3–5 minutes.
4. After the app is live, open it and check that the header reads **5,553 TWh** with the sidebar at its defaults.

Before pushing, ask the user to confirm the repo name and that it can be public. Commit only on the user's request.

## Layout
- `streamlit_app.py`: the dashboard, with seven tabs. Every slider re-runs the models below.
- `model/`:
  - `demand_v1.py`: state panel demand model.
  - `regional.py`: roll-up to CEA regions.
  - `mix_lp.py`: least-cost mix, as a linear programme solved with PuLP and HiGHS.
  - `pathway.py`: FY30/35/40/47 milestones.
  - `run_mix.py`: scenarios plus 13 verification checks.
  - `simulate_v1.py`: Monte Carlo.
  - `export_dashboard.py`: data for the backup dashboard.
- `data/`: `build_*.py` builds every input table from public sources; `validate_all.py` runs 16 checks.
- `out/`: model outputs the app reads (tornado, Monte Carlo, backcast, benchmarks, tests). They are regenerated by `python run_all.py`.
- `tests/test_app.py`: drives the app through 15 interactions with Streamlit AppTest.
- `ingest_official.py`: compares the official 13 Nov datasets with our tables.

## Rules
- Metric is electricity **generated** (TWh), never capacity or consumption.
- The six sources are coal, hydro, solar, wind, nuclear and natural gas. The five regions follow CEA.
- After any change to `data/` or `model/`, run `python run_all.py` and then `python tests/test_app.py`. Both must pass before you commit.
- Do not add ExxonMobil logos or trademarks. Keep the AI-use disclosure in the app.
